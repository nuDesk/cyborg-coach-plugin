# Cyborg Coach

Learn by doing in Claude Code Desktop: get started, ask practical questions, create a project-based agent, or build your organization's operating system from real work or a clearly fictional example.

Version 0.5.2 · supervised Mac preview.

## Install

Follow the [illustrated guide](https://nudesk.github.io/cyborg-coach-guide/#install) or [installation steps](INSTALL.md). In Claude, add this public marketplace URL, then install Cyborg Coach:

```text
https://github.com/nuDesk/cyborg-coach-plugin.git
```

No GitHub account or invitation is required. This is a custom public marketplace you add inside Claude, not an automatic listing in Claude's default directory. Claude Desktop and working Claude Code access are prerequisites.

Start a Code → Local session in your work folder, select `/cyborg-coach:start` from the dropdown, and send it. Choose any of the four lanes. Refresh the marketplace and update the plugin for later releases, then check it in a fresh session.

## What is included

Ten skills, 18 reference documents, templates, and a static macOS session-start hook. The package is standalone: its methods are informed by nuDesk OS, but it does not include or connect to nuDesk's actual OS, company wiki, or client projects. Package instructions and references are readable on your computer.

Your organizational context, procedures, references, decisions and lessons belong in your own OS. Projects and their inputs/outputs remain separate; a wider wiki or memory system is optional.

## Privacy and limits

The plugin adds no connectors, telemetry, or publisher access to your conversations or files. Claude uses the tools and file permissions you grant, and relevant content is processed by Anthropic. Review permissions and start with non-sensitive material. Public repository issues are visible to everyone.

This is a supervised Mac preview. Prior bounded tests covered real-work intake, fictional OS creation, approved lesson application and shared-skill reuse. Some completion claims and rule interpretations required reviewer correction; review generated work. Windows automatic bootstrap and loading participant-created plugins are not established. Public distribution delivery checks are separate from coaching behavior tests.

See [release notes](CHANGELOG.md). RELEASE.json identifies the source commit and file hashes for this published package; it contains no private source history.
